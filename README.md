# Projects 

## StoreScout API

- **Description :** Developed an API that provides product availability and store details based on user location, helping users find their desired products without visiting multiple stores.
- **Objective :** Reduces the hassle of visiting multiple stores by providing the most optimal store(s) where all or most desired items are available.
- **Key Features :**
    - Finds stores with the least number of visits required.
    - Provides directions to selected stores.
    - Enhances shopping efficiency through smart product availability tracking.
- **Result :** Improved shopping convenience and reduced unnecessary store visits.
- **Tech Stack :** Go, PostgreSQL, Redis, Google Maps API, OAuth, JWT, Prometheus, Grafana, Docker.
